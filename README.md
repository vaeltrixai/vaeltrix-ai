## 🚀 Apa itu VaeltrixAI?

**VaeltrixAI** adalah AI assistant berbasis web yang dirancang untuk berjalan cepat di perangkat apapun — dari HP entry-level sampai desktop. Dibangun sebagai **Progressive Web App (PWA)**, kamu bisa install langsung ke homescreen tanpa perlu download dari app store.

> 💡 **Visi**: AI yang accessible untuk semua orang, tanpa perangkat mahal, tanpa install ribet.

## 🛠 Tech Stack

```
├── HTML5          → Struktur & Semantic
├── CSS3           → Styling & Animasi
├── Vanilla JS     → Logic & Interactivity (no framework!)
├── PWA APIs       → Service Worker, Manifest, Cache
├── Supabase       → Backend & Database (on migration)
└── GitHub Pages   → Hosting (planned)
```

> Kenapa Vanilla JS? Karena **ringan**, **cepat**, dan **tidak perlu build step**. Bisa diedit langsung di browser!

## 📦 Cara Menjalankan

### 1. Clone Repo
```bash
git clone https://github.com/vaeltrixai/vaeltrix-ai.git
cd vaeltrix-ai
```

### 2. Jalankan di Local
Karena ini pure HTML/CSS/JS, cukup buka file `index.html` di browser:

**Opsi A: Direct Open**
```bash
# Mac/Linux
open index.html

# Windows
start index.html
```

**Opsi B: Live Server (Recommended)**
```bash
# Pakai Python
python -m http.server 8000

# Atau pakai Node.js (npx)
npx serve .

# Atau pakai PHP
php -S localhost:8000
```

Lalu buka `http://localhost:8000` di browser.

### 3. Install sebagai PWA
1. Buka di browser (Chrome/Edge/Safari)
2. Klik icon **"Add to Home Screen"** atau **"Install"**
3. Selesai! 🎉
